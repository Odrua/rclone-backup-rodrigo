# Rclone Backup Rodrigo

Aplicativo de uso pessoal para realizar cópias de segurança dos meus arquivos utilizando o rclone e o Google Drive.

O aplicativo acessa exclusivamente as contas autorizadas por mim e não é disponibilizado comercialmente.

## Privacidade

O aplicativo utiliza a API do Google Drive para transferir, consultar e organizar arquivos durante as operações de backup.
